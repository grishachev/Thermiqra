## Application removal, from start to verified result

The new application-management area lists supported installed Windows and Microsoft Store applications. Thermiqra saves observed installation/change information and a pre-removal snapshot, runs the native uninstaller and then inspects supported leftover locations.

Thermiqra's own stages stay in one window with visible progress. Vendor uninstallers can still open their own interface. Cancelled, failed, incomplete and restart-pending removal have distinct outcomes; a disappearing list entry no longer means the saved removal attempt disappears with it.

Eligible confirmed leftovers are selected by default. Files/settings are grouped compactly, with evidence available on demand. Shared, protected and ambiguous objects are separated. Before cleanup, Thermiqra rechecks current contents, ownership, links and other installed applications.

Eligible files go to the Windows Recycle Bin. Supported registry cleanup saves typed recovery data first. Restore-point handling reports failures and respects Windows limits. Recovery checks for collisions rather than overwriting replacement data.

**After cleanup, a new inspection runs automatically.** The result immediately shows no leftovers in checked locations, remaining objects or inspection limitations. The per-object journal is available without filling the result screen.

Other fixes include immediate progress when searching from history, improved icon lookup, ordering within the same installation day, confirmed external product data for MSIX applications and supported stale-registration handling with its own confirmation.

## CPU detail and a compact tray panel

CPU detail includes logical-processor load and improved core/thread and clock presentation. The new background panel shows CPU/GPU temperatures and load, plus RAM usage, using the existing monitoring snapshot.

Hover over the tray icon by default, or enable persistent display in Settings. Cyber Tech, SteamPunk, Frost Core and Military Ops each have their own panel design. The panel does not take keyboard focus. Missing sensor data remains unavailable.

Moving across the taskbar does not dismiss the persistent panel. Neighboring tooltips can appear above it; opening a tray menu temporarily hides it. Detection also accounts for custom menus and excludes background overlays that previously caused false hiding.

## Storage, hardware and interface improvements

- Total, used and free drive capacity now stand out at the top of the Storage Analyzer.
- Additional graphics/storage information sources improve supported detection cases; absent SMART evidence still does not mean a disk is healthy.
- English/Russian text and application-owned error messages have been corrected across settings, diagnostics, removal and updates.
- Themed progress, compact leftover lists and automatic result verification reduce window switching and repetitive actions.
- A bounded update prompt shows the main changes, with a link to the complete release description.

## Stronger verification for subsequent updates

The new updater verifies the installer with an embedded project public key and SHA-256, checks the signed version/name/size/hash and verifies again before launch. Missing or invalid required evidence stops that update. Release signing uses an offline project key; no paid Authenticode certificate is required.

**Important transition:** existing installations receive this release through their old updater. The new signature checks protect later updates after this release is installed. These signatures do not remove SmartScreen warnings or change Windows publisher text. Settings and monitoring statistics are preserved by the update flow.

## Checks and practical limits

Automated checks cover storage interpretation, path/registry protections, shared products, recovery, process/restart handling, update integrity/signatures, localization, themed layouts and tray-window behavior. A Windows CI workflow is included.

A separate disposable-Windows run completed **16 EXE/MSI scenarios with 424 successful assertions on November 16, 2026**. It used purpose-built installers and independent checks; it is not a claim that every third-party application or every later revision received the same guest run. Full System Restore rollback remains separate from file/registry recovery tests.

Application cleanup remains evidence-based and bounded. Selected application data folders can contain accounts, settings, projects or saves. Windows-managed Store package files, shared components and unrelated data are protected. Arbitrary services, drivers, tasks, firewall rules and shell extensions are not universally removed. “No leftovers” means none were found in the successfully checked locations.

For the full development change log, see [CHANGELOG.md](https://github.com/grishachev/Thermiqra/blob/main/CHANGELOG.md). Requirements: **Windows 10/11 x64**, with administrator rights and supported hardware/driver access.
