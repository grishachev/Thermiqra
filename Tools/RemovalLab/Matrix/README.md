# Полный набор проверок удаления

## Текущее состояние

16 ноября 2026 выполнен реальный прогон в Песочнице Windows: **16 сценариев Passed, 424 успешные проверки, 0 неуспешных**. Использованы текущие службы Thermiqra, настоящие EXE и пять MSI. Локальные автоматические проверки отдельно прошли: 184, ошибок 0. Отчёт: [Reports/2026-11-16.json](Reports/2026-11-16.json).

После настоящей перезагрузки гостя RunOnce не запустил продолжение автоматически: запись оставалась в реестре. Продолжение запущено вручную через защищённый MatrixResume в том же госте. Первоначально финальная сверка упала в самом наборе проверок: Fixture.Load применял проверку ссылок к уже отсутствующим файлам. Исправлена только проверка манифеста; исходный неуспешный отчёт сохранён отдельно. Повторная сверка подтвердила отсутствие всех собственных каталогов и записей и сохранность соседних данных. Поэтому автоматический запуск через RunOnce не считается проверенным, а обработка требования и снятия блокировки после реальной перезагрузки — проверена.

| Сценарий | Проверяемый результат |
| --- | --- |
| Normal | Штатный EXE завершился, известные файлы и настройки очищены, соседние данные не изменились. |
| PartialError | EXE вернул ошибку после исчезновения записи; попытка остаётся в истории, остатки доступны для проверки и очистки. |
| Error | EXE вернул ошибку и оставил регистрацию; дополнительная очистка заблокирована. |
| Cancel | EXE завершился с кодом 0, но сохранил регистрацию; это не объявляется успешным удалением. |

| Shared | Вложенный каталог другой зарегистрированной программы и DLL со счётчиком SharedDLLs; чужие файлы, регистрация и счётчик сохраняются. Неполный результат не объявляется полной очисткой. |
| Reparse | Символьная ссылка ведёт к соседним данным; переход и автоматическое удаление исключены, соседние данные сохраняются. |
| Restore | Реальная служба восстановления Thermiqra возвращает типизированные настройки реестра. Тест отдельно возвращает только свои известные папки из Корзины и сверяет SHA-256 всех файлов. |

## Границы и безопасность

- Запускатель вызывает настоящие `InstalledProgramUninstallService`, `ProgramInstallationMemory`, `ProgramLeftoverRecheckService`, `ProgramLeftoverCleanupService` и восстановление. Код Thermiqra для образцов не содержит правил по названиям программ.
- Приложение Thermiqra и аппаратный монитор не запускаются. Драйверы, службы и сетевые правила образец не устанавливает. Весь набор относится к обычным EXE/MSI, не ко всем возможным программам Windows.
- Записи создаются только в тестовой гостевой Windows. До любых изменений проверяются модель виртуальной машины, административный токен и явный флаг режима испытаний. На обычном рабочем ПК выполнение блокируется.
- Общий раздел издателя содержит соседние контрольные подразделы: удаление всего издателя повредит контрольную сумму и провалит проверку.
- Каталоги `ThermiqraMatrixControl`, `ThermiqraMatrixNeighbors`, временные EXE тестовых деинсталляторов и отчёты — инфраструктура проверки. Они намеренно не выдаются за остатки очищаемой программы.
- Корзина целиком не очищается. Восстановление из неё касается только точных исходных путей текущего образца; занятый адрес не перезаписывается.
- Источники и отчёты разделены: исходный пакет подключается к Песочнице только для чтения. Для записи на хост доступна только новая папка результатов. Сеть и буфер обмена отключены.
- Положительный результат требует завершения всех сценариев. Исключения, недоступные источники, незавершённая перезагрузка и отсутствующий гость не засчитываются как пройденный полный прогон.

Набор не восстанавливает Windows целиком из системной точки. Это отдельная проверка в полной виртуальной машине со снимком и доступным System Restore. Тестирование реальной перезагрузки в Песочнице требует Windows 11 22H2 или новее, где состояние гостя сохраняется при внутреннем перезапуске. Закрытие окна Песочницы уничтожает гостя.

## Запуск

1. Собрать: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\RemovalLab\Matrix\Build-Matrix.ps1`. Сборка ничего не устанавливает на компьютер и не запускает сценарии. При необходимости локально восстанавливает закреплённый WiX 5.0.2.
2. Включить Песочницу Windows системными средствами. Подготовленный `Enable-Sandbox.ps1` требует администратора, включает только `Containers-DisposableClientVM` с зависимостями и **не перезагружает рабочий компьютер**. Windows может запросить перезагрузку.
3. После готовности Песочницы выполнить `Start-Sandbox.ps1`. Внутри гостя при необходимости подтвердить повышение прав.
4. Дождаться отчёта `bin/Results-<время>/matrix-results.json`. После требования перезагрузки ожидается продолжение внутри того же гостя. Если RunOnce не запустился, открыть в гостевом Проводнике `C:\LabSource\AA-Resume\MatrixResume.exe`: он проверяет виртуальную Windows, права и маркер исходного гостя, затем продолжает существующий отчёт. Итоговый Passed возможен только после продолжения. Режим повторной сверки сохраняет исходный неуспешный отчёт, допускает только последний сценарий перезагрузки при остальных 15 Passed и не подменяет результаты остальных сценариев.
5. После сохранения результатов закрыть Песочницу. Для повторного прогона запускается новый чистый гость.

Пакет автономный: .NET поставляется рядом с запускателем, интернет внутри гостя не требуется. Около 200 МБ файлов — инструменты и среда выполнения, а не установленные на хост тестовые программы.
