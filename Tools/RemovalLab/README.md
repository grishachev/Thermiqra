# Thermiqra Removal Lab

Отдельное тестовое приложение и установщик для полного цикла удаления. Не входит в поставку Thermiqra. Не требует загрузки дополнительного .NET: использует .NET Framework Windows.

16 ноября 2026 пользователь выполнил установку и удаление образца. Независимая проверка этапа Cleaned на текущем компьютере прошла: 77 проверок, 0 ошибок. Отдельные проверки Installed/Native и восстановление ещё не выполнялись. Для следующих полных прогонов предназначена виртуальная Windows.

## Что проверяется

- Штатный установщик и деинсталлятор Inno Setup, запись Windows, ярлык меню «Пуск».
- 65 заранее известных файлов в папке установки, Roaming и Local: вложенные каталоги, настройки, плагин, журнал и 60 файлов кэша. Их создаёт приложение после установки, поэтому штатный деинсталлятор намеренно оставляет их.
- Настройки HKCU `Software\ThermiqraLab\ThermiqraRemovalLab`: строка, DWORD, массив строк, бинарные данные.
- Соседний контрольный файл и раздел `Software\ThermiqraLab\Neighbor` должны остаться неизменными. Общий раздел издателя нельзя удалять целиком.
- Независимая проверка использует сохранённые пути, идентификатор запуска и SHA-256, а не результат поиска Thermiqra. После очистки проверяет также отсутствие самих папок, включая любые дополнительные файлы внутри.

На 64-битной Windows HKCU Software может иметь общее представление: две проверки не означают два разных физических раздела.

## Проверка в виртуальной Windows

1. Создать чистый снимок виртуальной машины. Скопировать туда установщик, `Verify-Lab.ps1` и проверяемую сборку Thermiqra.
2. Установить `bin/Installer/ThermiqraRemovalLab_Setup.exe`. Права администратора образцу не нужны. Установка сама создаст данные.
3. Выполнить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Verify-Lab.ps1 -Stage Installed` — исходные данные должны совпасть.
4. Открыть Thermiqra, обновить список, выбрать **Thermiqra Removal Lab**. Дать программе сохранить снимок до удаления. Выполнить штатное удаление, пока не очищать остатки.
5. Выполнить проверку `-Stage Native`: штатная регистрация исчезла, известные остатки и соседние данные сохранились.
6. Очистить найденные остатки через Thermiqra. Выполнить проверку `-Stage Cleaned`: все три папки образца и его настройки отсутствуют, соседние данные целы.
7. Для следующего сценария вернуть чистый снимок виртуальной машины. Образец откажет в повторной установке поверх занятых контрольных путей.

Результат каждого этапа сохраняется в `%LocalAppData%\ThermiqraLabVerification\verification-<этап>.json`. Этот каталог специально находится вне очищаемых путей. Проверяющий сценарий ничего не удаляет и не изменяет в реестре; он записывает только свой отчёт.

Этот образец проверяет обычное пользовательское приложение с несколькими расположениями данных. MSI, Appx, службы, драйверы, отложенную перезагрузку и все существующие программы он не моделирует. Подготовка и сборка образца не считаются прохождением реального цикла в виртуальной машине.

## Повторная сборка

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\RemovalLab\Build-Lab.ps1`

Нужен установленный Inno Setup 6. Сценарий сборки только создаёт EXE и установщик, не запускает их. Для другого расположения компилятора предусмотрен параметр `-Compiler`.
