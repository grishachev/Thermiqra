# Проверка локализации

Проверяются строки C# через Roslyn и подписи XAML через XML. Инструмент не запускает Thermiqra, мониторинг, установщики или удаление программ.

```powershell
dotnet run --project Tools/LocalizationAudit/LocalizationAudit.csproj
dotnet test Thermiqra.Tests/Thermiqra.Tests.csproj -c Debug --filter FullyQualifiedName~LocalizationTests
```

Результаты аудита находятся в bin/audit.json, bin/audit.txt, bin/audit.english.txt и bin/audit.pairs.txt. Список кандидатов предназначен для ручной проверки: отсутствие прямого L(...) не обязательно означает отсутствие перевода.

16 ноября 2026 просмотрены 217 файлов C# и 11 XAML, проверены 376 общих переводов. Добавлены 56 отсутствовавших общих переводов и русские варианты собственных ошибок служб. Английские ветви L(...) не содержат русских литералов. Все статические подписи XAML имеют английский перевод; отдельная проверка охватывает словарь RingGauge.

Оставшиеся 136 кандидатов просмотрены: собственный двуязычный словарь и подписи RingGauge, пары Ru/En в моделях и кортежах, русские формы множественного числа внутри русской ветви, строки распознавания названий Windows и регулярных выражений. Это не список 136 непереведённых элементов. Девять английских диагностик чистого формата подписи закрыты локализованной UpdateSignaturePolicy; три заголовка STORAGE NAVIGATOR являются намеренными надписями тем.

Проверки создают изображения шести статических окон (главное, настройки, система, статистика, анализ диска, уведомление) и четырёх состояний анализа остатков на обоих языках для всех четырёх тем. Дополнительно проверяется минимальная ширина окон. Конструкторы основных окон с аппаратным мониторингом и обработчики событий не запускаются: проверяется разметка и оформление; реальные аппаратные данные не подставляются. Состояния остатков создаются из синтетических отчётов настоящим компонентом интерфейса. Всего сохранено 120 изображений вне репозитория в `B:\Projects\Thermiqra_Backups\Localization-Previews-20261116` и просмотрены общие листы и отдельные изображения.

Для сохранения новых изображений задать `THERMIQRA_LOCALIZATION_PREVIEWS` перед тестами. Тесты не сохраняют изменённый язык в настройки пользователя. Имена сторонних программ, пользовательские пути и сообщения самой Windows не переводятся этим словарём.
