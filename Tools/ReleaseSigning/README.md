# Бесплатная подпись обновлений Thermiqra

Используется ECDSA P-256 / SHA-256 из .NET, без Authenticode и платного сертификата. Подписываются версия, имя установщика, размер и SHA-256. Открытый ключ встроен в UpdateSigningKey.cs. Закрытый ключ не нужен пользователям или GitHub Actions.

## Ключи автора

Основная пара уже создана в `%USERPROFILE%\.thermiqra-signing`, резервная — вне репозитория в `B:\Projects\Thermiqra_Release_Keys`. Доступ к каталогам ограничен текущим пользователем и SYSTEM. Закрытый файл `release-private.pk8` содержит секрет; `release-public.spki` — открытый ключ. Содержимое закрытого файла нельзя публиковать, отправлять в чат или добавлять в CI. Резервную копию следует дополнительно перенести на отдельный отключаемый носитель: две локальные папки не защищают от потери всего компьютера.

Не запускать `init` повторно и не менять открытый ключ в уже выпущенной программе без отдельно продуманного перехода. Проверка ключа не раскрывает секрет:

```powershell
dotnet run --project Tools/ReleaseSigning/ReleaseSigning.csproj -- verify-key "$env:USERPROFILE\.thermiqra-signing"
```

## Каждый новый выпуск

После окончательной сборки установщика выполнить из корня проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Tools\ReleaseSigning\Sign-Release.ps1 -Installer .\Installer\Output\Thermiqra_Setup_1.0.1.exe
```

Номер здесь — пример; скрипт берёт версию из имени установщика. Он создаёт и проверяет два файла рядом с ним:

- `Thermiqra_Setup_<версия>.exe.signature.json` — обязательная подпись для нового обновлятора;
- `Thermiqra_Setup_<версия>.exe.sha256` — открытая контрольная сумма для ручной сверки.

Загрузить в один релиз все три файла: установщик, подпись и контрольную сумму. Скрипт не публикует релиз и не запускает установщик. Повторный запуск допускается для неизменённого установщика: существующая подпись проверяется. При изменении установщика старые сопроводительные файлы не перезаписываются автоматически.

Независимая проверка готового комплекта не требует закрытого ключа:

```powershell
dotnet run --project Tools/ReleaseSigning/ReleaseSigning.csproj -- verify-release .\Installer\Output\Thermiqra_Setup_1.0.1.exe 1.0.1
```

## Переход и ограничения

Старая выпущенная Thermiqra скачает переходный выпуск по своей прежней схеме. Проверка новой подписи заработает для последующих обновлений после установки переходного выпуска. Первая установка, защита GitHub-аккаунта и сохранность закрытого ключа остаются отдельными задачами. Платная подпись Windows не добавляется, SmartScreen и отображение издателя в UAC этим механизмом не меняются.

Обновлятор требует SHA-256 из сведений официального релиза, проверяет HTTPS-источник и подпись после скачивания и повторно перед запуском. Проверка привязана к точной версии, имени и размеру файла, поэтому подписанный старый установщик не подходит под метаданные нового выпуска. Неподписанные будущие обновления этим новым механизмом не допускаются — это согласованная бесплатная подпись своим ключом.
